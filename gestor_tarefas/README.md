# 📋 Gestor de Tarefas (To-Do List)

Um to-do list simples feito em Tkinter.

## O que faz

- Adiciona tarefas com nome e prioridade (1 a 10)
- Ordena automaticamente por prioridade
- Remover uma tarefa ou limpar tudo
- Contador de tarefas no rodapé

## Requisitos

- [Python 3](https://www.python.org/downloads/)

> ⚠️ Em Linux o Tkinter pode não vir instalado:
>
> ```bash
> # Debian/Ubuntu
> sudo apt install python3-tk
>
> # Fedora
> sudo dnf install python3-tkinter
>
> # Arch
> sudo pacman -S tk
> ```

## Como correr

```bash
python gestor_tarefas.py
```
